# CivicVoice - Frontend Application

Direktori ini dipersiapkan untuk aplikasi antarmuka pengguna (Frontend) CivicVoice.

## Rencana Tech Stack
- **Framework**: Next.js (React)
- **Styling**: Tailwind CSS
- **Peta & Geospasial**: Leaflet / React-Leaflet + OpenStreetMap
- **State/Data Fetching**: SWR / TanStack Query

Aplikasi antarmuka akan dibangun pada tahap pengembangan frontend setelah API backend (Modul Auth, Complaints, Triage, SLA, dan Public) selesai diimplementasikan dan diuji.
